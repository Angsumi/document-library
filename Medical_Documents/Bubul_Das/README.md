# Bubul Das — medical records, 2005–2026

- **[Bubul_Das_Medical_Records_Chronological.pdf](Bubul_Das_Medical_Records_Chronological.pdf)** — 26 records in date order, each with a copyable text transcription followed by the source photo (59 pages), plus an index and a thyroid-function trend table.
- **[INDEX.csv](INDEX.csv)** — one row per photo: date, document, provider, summary, original filename, renamed file, SHA-256.
- **Originals/** — the 29 original photos, byte-for-byte unchanged, renamed `YYYY-MM-DD_Document_Provider.jpg`. Originals are not rotated; the PDF shows them upright.
- **Other_Family_Not_Bubul_Das/** — 5 photos of other family members' reports, kept out of the PDF (see MAPPING.csv).

Typed reports were transcribed directly. Handwritten prescriptions are best-effort; values marked [?] are uncertain — check against the photo. Dates are as printed/written on each document.
