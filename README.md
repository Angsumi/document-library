# Angsumi Document Download Centre

[Open the download page](https://angsumi.github.io/document-library/) · [Sequencing downloads](https://github.com/Angsumi/document-library/releases/tag/sequencing-data-v1)

547 organized records, with downloadable originals, searchable PDFs and plain-text transcripts. The page searches names, categories, source names and extracted text, and works on mobile.

Document files and OCR derivatives are in `Library/`. The 304 sequencing `.fastq.gz` originals are attached individually to the `sequencing-data-v1` release to keep the Pages deployment below GitHub’s 1 GB limit. Their download URLs are included in `catalog.json`. The CSV and SQLite indexes preserve the original local paths.

OCR can contain errors; check important details against original scans. Distinct document versions are retained and duplicates have been removed. See [duplicate cleanup](DUPLICATES.md) and [review notes](REVIEW_NEEDED.md).

This repository and website are public, including identity, banking and family documents, as explicitly authorized by the owner. No account credentials, local configuration or prior Git history are included.
